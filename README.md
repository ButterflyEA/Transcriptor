# Transcriptor

A from-scratch Rust implementation of [OpenAI Whisper](https://github.com/openai/whisper)
running on [burn](https://burn.dev), with a native desktop app and a
command-line tool.

Nothing here wraps the original Python implementation — the model, tokenizer,
audio frontend and beam search are all reimplemented, and the output is checked
against the official implementation token for token (see
[Fidelity](#fidelity)).

## Download

| Platform | File | Notes |
|---|---|---|
| Windows x64 | `Transcriptor_1.0.0_x64-setup.exe` | NSIS installer, unsigned |
| Windows x64 | `Transcriptor_1.0.0_x64_en-US.msi` | MSI installer, unsigned |

Linux artefacts are not attached to this release yet. `tauri.linux.conf.json`
configures AppImage, deb and rpm targets, so `tauri build` on Linux produces all
three — see [**docs/linux-build.md**](docs/linux-build.md), which also covers
the glibc baseline problem with building portable packages on Arch.

Windows binaries are **not code-signed**, so SmartScreen will warn on first
run. Choose *More info → Run anyway*.

Model weights download on first use and are cached per model
(`~/.cache/whisper-burn`); nothing is uploaded, and transcription runs entirely
on your machine.

## The desktop app

Pick a model, drop in an audio or video file, and export `txt`, `srt`, `vtt`,
`json` or `docx`. Language detection is automatic, and the detected language
travels with the `json` export so downstream tools see what was actually spoken.

## Command line

```sh
whisper-burn-cli speech.wav
```

Prints timestamped segments to stdout and can write a transcript next to your
audio file:

```sh
whisper-burn-cli interview.flac --model base --output srt
```

For options, examples, output formats, model downloads and troubleshooting see
[**docs/usage.md**](docs/usage.md).

## Layout

- **`crates/whisper-burn`** — the library: model definition, weight loading,
  tokenizer/BPE, log-mel, timestamp rules, greedy and beam decoding,
  transcription orchestration, and transcript formatting.
- **`crates/whisper-burn-cli`** — the command-line frontend (wgpu or ndarray
  backend).
- **`crates/transcriptor`** — the Tauri desktop app (Rust backend, web UI).

## Fidelity

A golden test compares our output against transcripts generated by
`openai/whisper` itself, one case per model, with the library version and
search settings recorded beside every file
([`docs/golden/`](docs/golden/README.md)).

On **large-v3 transcribing Hebrew** — the model and language people actually
use — our output matches the reference **byte for byte**: same detected
language, same segment count, all six timestamp boundaries, and all three
transcripts character for character.

Across smaller models we track the reference closely but not identically
(0–9 characters over a whole transcript), because our arithmetic is not
PyTorch's and nearly-tied tokens can flip. Language detection is correct in
every case. The test gate is layered accordingly, and every known divergence is
written down rather than smoothed over.

## Building

```sh
cargo build --release -p whisper-burn-cli
cd crates/transcriptor && npm install && npm run tauri build
```

The golden suite is opt-in, since it downloads model weights:

```sh
cargo test --workspace                                # offline suite
cargo test -p whisper-burn-cli --test golden_models -- --ignored   # vs reference whisper
```
